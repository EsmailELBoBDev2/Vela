# نسخة ملفات بيئة كايرو درايف والبحث

هذه لقطة بحث كاملة قابلة للتحقق والاسترداد، وليست إعلانًا باكتمال تحليل التطبيقات. تشمل المدخلات الأصلية وملفات APK، الكود والموارد والأصول المستخرجة، مخرجات الاستعادة والأدلة ومشاريع الأدوات، نقاط الحفظ وقوائم التغطية، برامج الاستمرار والعمل المؤقت وإصلاحات الأدوات الخاصة. جميع أجزاء الأرشيف لها بصمات، وكل ملف محفوظ له بصمة للبايتات الملتقطة.

استُبعدت بيانات الدخول وقواعد بيانات جلسات النموذج والسجلات الخاصة بها وإدارة Git وكاش بايثون. تفاصيل الاستبعادات والعدد في فهرس اللقطة. تبقى الملفات الأصلية والمشاريع المصدرية غير معدّلة.

رفض GitHub رفع كائنات Git LFS جديدة لأن فيلا مستودع مشتق عام، ومنعت صلاحيات الاتصال إنشاء مستودع مستقل. إنشاء مسودة إصدار نجح لكن رفع أصولها أعاد خطأ مصادقة من نطاق الرفع. لذلك قُسمت الأرشيفات إلى أجزاء لا تتجاوز ٣٢ ميبيبايت وتُرفع بوساطة Git العادي على دفعات دون تجاوز حد الملف أو حد الرفع. لا توجد مؤشرات Git LFS مكسورة بدل البيانات، ولا نعتمد على إصدار مسودة فارغ. النسخة كبيرة، لذلك استخدم تنزيل الفرع وحده؛ لا ترفع إصدارات كاملة جديدة باستمرار.

وافق المستخدم صراحة على الرفع بينما المستودع عام؛ هذا لا يمنح ترخيصًا لإعادة استعمال الكود المغلق.

## الاسترداد

ثبّت Git وبايثون حديث وأداة GitHub الرسمية وسجّل الدخول إذا لزم:

```bash
git clone --branch research-backup --single-branch https://github.com/EsmailELBoBDev2/Vela.git cairodrive-research-backup
cd cairodrive-research-backup
python3 scripts/restore_backup.py --verify-only
python3 scripts/restore_backup.py --destination /workspace-restored
```

اختر مجلدًا جديدًا فارغًا؛ الاسترداد يرفض الكتابة فوق بيئة قائمة. يعيد المحتويات ثم يعطّل التشغيل التلقائي في النسخة المستعادة ويحفظ أرقام العمليات والمحادثة القديمة كتاريخ. أعد تجهيز الأدوات من البرامج والمراجع المحفوظة، وسجّل الدخول بالطريقة الرسمية ثم استأنف من ملفات الهدف والتغطية ونقاط الحفظ بفريق غير مكرر. الصور المثبتة العامة ونظام التشغيل بالكامل والمحادثات الداخلية للنموذج ليست صورة آلة افتراضية ضمن هذه النسخة.

استمر البحث أثناء النسخ. اللقطة تتحقق من كل ملف منفردًا ومن عدم تغيّره أثناء القراءة، لكنها ليست معاملة متوقفة لكل الجهاز. راجع نقاط الحفظ عند الاسترداد وأعد بناء مشروع أداة من المدخلات والأدلة إذا اكتشف عدم اتساق قاعدة بيانات. وصلة الأرشيفين المتطابقين محفوظة بعد فحص البصمات، والروابط الداخلية أعيدت بصيغة نسبية. النسخة مؤرخة ولا تشمل تلقائيًا النتائج التي تُنتج بعدها.

الأجزاء داخل مجلد البيانات في هذا الفرع، وليس ضمن أصول إصدار. استعمل النسخ بالفرع الواحد لضمان تنزيل الملفات المتتبعة في Git. يستمر البحث في البيئة الأصلية؛ هذه لقطة مؤرخة وليست اكتمالًا للهدف.

## نتيجة التحقق

اكتمل رفع ١٥٩ جزءًا بإجمالي ٥٬٢٠٢٬٠٩٩٬٤٣٣ بايت. نُزّل كل جزء من GitHub عند معرّف الالتزام الثابت المحفوظ في تقرير التحقق، وطابق الحجم وبصمة SHA-256. جميع سجلات الأرشيفات البالغ عددها ٥٠١٬٤٦٤ خضعت لفحص محلي كامل؛ يشمل العدد سجلات التحديث المتكررة وليس بالضرورة ملفات فريدة. واختُبر استرجاع ثلاث مجموعات منزّلة من GitHub إلى مجلد فارغ، بإجمالي ١٢٢٠ سجلًا، ثم تعطيل التشغيل التلقائي في النسخة المستعادة. تفاصيل الفحص في `manifests/remote-verification.json`.

## التوسعة إلى كل ملفات العمل

أضيفت مجموعة `workspace-supplement` للمشاريع Vela وCairoDrive وOsmand وCoMaps وOrganic Maps وREA، وبقية ملفات `/workspace` غير المحفوظة سابقًا، بما فيها الأدوات وAndroid SDK وJava وكاش الاعتمادات وملفات العمل ونتائج البحث الأحدث. شملت الإضافة ١٣٦٬٠٦٦ سجلًا و١٣٬٧٤٨٬٥٣٣٬٤١٣ بايت غير مضغوط؛ تحقق محلي من كل محتواها. حُفظ تاريخ Git المتاح في ١٣ حزمة واختُبرت جميعها داخل مستودع فارغ. لا تشمل النسخة حسابك وبيانات الدخول والعمليات الحية أو صورة نظام التشغيل، ولا تنسخ مجلدات تجهيز النسخ والاسترداد المكررة. قائمة التغطية والاستثناءات والروابط الخارجية في `manifests/workspace-audit.json`. انتهت لقطة الملفات دون تغير أي ملف أثناء قراءته؛ لا تزال لقطة بيئة حية وليست معاملة متوقفة.

بعد استرداد كل المجموعات إلى بيئة جديدة فارغة ومتوافقة، يمكنك إعادة تاريخ مستودعات المصدر دون تغيير ملفاتها المحفوظة:

```bash
python3 /workspace-restored/workspace-environment/git-restore.py /workspace-restored
```

عند مطابقة نظام التشغيل ووجود الملفات النظامية المطلوبة، يسمح خيار `--restore-system-links` بإعادة الروابط الست الخارجية الموثقة نحو النظام. البرامج المثبتة داخل البيئات الافتراضية قد تتضمن المسار الأصلي `/workspace` في ملفات التشغيل؛ لاسترداد مطابق استخدم جهازًا جديدًا ومجلد `/workspace` فارغًا، ولا تسترد فوق المشروع الجاري. جرد حزم النظام والإصدارات محفوظ في `workspace-environment`. ابدأ ثلاثة وكلاء ومشرفًا جديدًا بعد الدخول الرسمي وفحص نقاط الحفظ والأقفال؛ لا تعتمد على أرقام عمليات البيئة السابقة. وفر نحو ٦٠ جيجابايت أو أكثر للنسخ التقليدي والاسترداد مع تاريخ Git؛ لا توجد مساحة كافية هنا لتجربة استخراج البيئة كلها دفعة واحدة. يُفحص الأرشيف كاملًا، وتُختبر الاستعادة الفعلية بصورة منفصلة.

## التحديث الأخير

تأتي مجموعة `workspace-final-overlay` أخيرًا. تحفظ ١٠٣٧ سجلًا إضافيًا/محدّثًا، بما فيها أحدث نتائج البحث ونقاط الحفظ و١٠ ملفات كانت استُبعدت بالاسم أو الشكل ثم ثبت أنها مخرجات JADX أو ملفات اختبار/إعدادات عامة مطابقة للمصدر. استثناء مفاتيح الدخول لا يحذف صنفًا مفكوكًا اسمه `auth`. ملفات الشهادات العامة داخل APK كانت محفوظة بالفعل. يحفظ التحديث إعدادات Git الأساسية وروابط المصدر دون بيانات اعتماد، وسكربت استعادة التاريخ الذي اختُبر فعليًا على Vela وCairoDrive.

اكتمل فحص كل بايتات ومحتويات الإضافة الكبيرة بعد تنزيلها من GitHub، واستعيدت نسختا Vela وCairoDrive بالكامل مع Git عند الالتزام الأصلي وشجرتين نظيفتين. الأدلة في `manifests/workspace-supplement-remote-verification.json` و`manifests/target-source-restore-verification.json`.
