# النسخة الكاملة لبحث كايرو درايف

هذه لقطة بحث كاملة قابلة للتحقق والاسترداد، وليست إعلانًا باكتمال تحليل التطبيقات. تشمل المدخلات الأصلية وملفات APK، الكود والموارد والأصول المستخرجة، مخرجات الاستعادة والأدلة ومشاريع الأدوات، نقاط الحفظ وقوائم التغطية، برامج الاستمرار والعمل المؤقت وإصلاحات الأدوات الخاصة. جميع أجزاء الأرشيف لها بصمات، وكل ملف محفوظ له بصمة للبايتات الملتقطة.

استُبعدت بيانات الدخول وقواعد بيانات جلسات النموذج والسجلات الخاصة بها وإدارة Git وكاش بايثون. تفاصيل الاستبعادات والعدد في فهرس اللقطة. تبقى الملفات الأصلية والمشاريع المصدرية غير معدّلة.

رفض GitHub رفع كائنات Git LFS جديدة لأن فيلا مستودع مشتق عام، ومنعت صلاحيات الاتصال إنشاء مستودع مستقل. لذلك توجد الأجزاء الكبيرة كأصول إصدار GitHub، بينما يحتوي هذا الفرع أدوات الاسترداد والفهارس فقط. لا توجد مؤشرات LFS مكسورة بدل البيانات. وافق المستخدم صراحة على الرفع بينما المستودع عام؛ هذا لا يمنح ترخيصًا لإعادة استعمال الكود المغلق.

## الاسترداد

ثبّت Git وبايثون حديث وأداة GitHub الرسمية وسجّل الدخول إذا لزم:

```bash
git clone --branch research-backup --single-branch https://github.com/EsmailELBoBDev2/Vela.git cairodrive-research-backup
cd cairodrive-research-backup
python3 scripts/download_release_assets.py
python3 scripts/restore_backup.py --verify-only
python3 scripts/restore_backup.py --destination /workspace-restored
```

اختر مجلدًا جديدًا فارغًا؛ الاسترداد يرفض الكتابة فوق بيئة قائمة. يعيد المحتويات ثم يعطّل التشغيل التلقائي في النسخة المستعادة ويحفظ أرقام العمليات والمحادثة القديمة كتاريخ. أعد تجهيز الأدوات من البرامج والمراجع المحفوظة، وسجّل الدخول بالطريقة الرسمية ثم استأنف من ملفات الهدف والتغطية ونقاط الحفظ بفريق غير مكرر. الصور المثبتة العامة ونظام التشغيل بالكامل والمحادثات الداخلية للنموذج ليست صورة آلة افتراضية ضمن هذه النسخة.

استمر البحث أثناء النسخ. اللقطة تتحقق من كل ملف منفردًا ومن عدم تغيّره أثناء القراءة، لكنها ليست معاملة متوقفة لكل الجهاز. راجع نقاط الحفظ عند الاسترداد وأعد بناء مشروع أداة من المدخلات والأدلة إذا اكتشف عدم اتساق قاعدة بيانات. وصلة الأرشيفين المتطابقين محفوظة بعد فحص البصمات، والروابط الداخلية أعيدت بصيغة نسبية. النسخة مؤرخة ولا تشمل تلقائيًا النتائج التي تُنتج بعدها.

للتنزيل اليدوي، افتح رابط الإصدار في ملف الفهرس وحمّل كل ملفات الأجزاء إلى مجلد البيانات، ثم شغّل أداة التحقق. ملفات ZIP العادية للفرع لا تتضمن أصول الإصدار. تظل الأبحاث المغلقة مراجع لتنفيذ مستقل، والإشعارات والتراخيص المؤهلة للمصادر الحرة محفوظة.
